Office ↔ PDF

DOCX/XLSX/PPTX/ODT/RTF/HTML/CSV/EPUB → PDF, dan PDF → DOCX/XLSX/PPTX/ODT/TXT/HTML. Ditenagai LibreOffice yang di-compile ke WebAssembly, jalan sepenuhnya di browser Anda.

Konversi pertama mengunduh runtime LibreOffice WASM ±240MB (wasm 147MB + data 99MB) lalu disimpan di cache browser; berikutnya cepat. File tidak pernah meninggalkan perangkat Anda. Halaman ini dimuat ulang sekali otomatis saat kunjungan pertama untuk mengaktifkan cross-origin isolation (SharedArrayBuffer).
